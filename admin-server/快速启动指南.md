# 🚀 简牍后台管理系统 - 快速启动指南

## 情况 1: 你已经安装了 MySQL

### 步骤 1: 确认 MySQL 正在运行

**方法 1: 检查服务**
1. 按 `Win + R`
2. 输入 `services.msc` 回车
3. 找到 `MySQL` 或 `MySQL80` 服务
4. 如果状态不是"正在运行"，右键 → 启动

**方法 2: 检查进程**
1. 按 `Ctrl + Shift + Esc` 打开任务管理器
2. 查看是否有 `mysqld.exe` 进程

### 步骤 2: 配置数据库

打开 MySQL 命令行或 Navicat，执行：

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS jiandu_admin CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

然后运行 `database.sql` 文件创建表。

### 步骤 3: 配置 .env 文件

用记事本打开 `.env` 文件：

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的 MySQL 密码
DB_NAME=jiandu_admin
JWT_SECRET=jiandu_admin_secret_2026
PORT=3000
```

### 步骤 4: 启动服务器

双击运行 `启动后台.bat`

## 情况 2: 你没有安装 MySQL（推荐方案）

### 方案 A: 使用 phpStudy（最简单）

1. **下载 phpStudy**
   - 官网：https://www.xp.cn/
   - 下载 Windows 版本
   - 安装后启动，会自动运行 MySQL

2. **配置数据库**
   - MySQL 密码通常是 `root`
   - 打开 phpStudy → 数据库 → 打开 phpMyAdmin
   - 创建数据库 `jiandu_admin`
   - 导入 `database.sql` 文件

3. **修改 .env 文件**
   ```env
   DB_PASSWORD=root
   ```

4. **启动后台**
   - 双击 `启动后台.bat`

### 方案 B: 使用 MySQL Installer

1. **下载 MySQL**
   - 官网：https://dev.mysql.com/downloads/mysql/
   - 下载 MySQL Installer for Windows
   - 安装时记住设置的 root 密码

2. **启动 MySQL 服务**
   - 安装完成后会自动启动
   - 或在 services.msc 中启动

3. **配置数据库**
   - 打开命令提示符
   - 输入：`mysql -u root -p`
   - 输入密码
   - 执行：`source D:\简牍_V2.0\admin-server\database.sql`

4. **修改 .env 文件**
   ```env
   DB_PASSWORD=你设置的密码
   ```

5. **启动后台**
   - 双击 `启动后台.bat`

### 方案 C: 使用 Docker（如果你熟悉 Docker）

```bash
docker run --name jiandu-mysql -e MYSQL_ROOT_PASSWORD=root123 -p 3306:3306 -d mysql:8.0
```

然后修改 `.env`:
```env
DB_PASSWORD=root123
```

## ❓ 常见问题

### Q: 不知道 MySQL 密码怎么办？

**Windows 重置方法：**

1. 停止 MySQL 服务
2. 创建文本文件 `reset.txt`：
   ```
   ALTER USER 'root'@'localhost' IDENTIFIED BY '新密码';
   ```
3. 以安全模式启动 MySQL：
   ```
   mysqld --init-file=C:\\path\\to\\reset.txt
   ```
4. 重启服务

### Q: 端口 3306 被占用？

检查是否有其他程序占用：
```cmd
netstat -ano | findstr :3306
```

### Q: npm install 失败？

使用淘宝镜像：
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### Q: 没有 MySQL，想快速测试？

可以先用在线 MySQL 服务或本地 SQLite（需要修改代码），但建议安装本地 MySQL 以获得完整体验。
