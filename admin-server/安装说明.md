# 简牍后台管理系统 - 安装指南

## 📦 系统要求

- Node.js 16+ 
- MySQL 5.7+ 或 MySQL 8.0+
- Windows / macOS / Linux

## 🚀 快速开始

### 1. 安装依赖

```bash
cd D:\简牍_V2.0\admin-server
npm install
```

### 2. 配置数据库

#### 2.1 创建 MySQL 数据库

打开 MySQL 命令行或工具（如 Navicat、phpMyAdmin），执行：

```sql
-- 如果还没有数据库，执行下面的命令
source database.sql
```

或者直接运行 `database.sql` 文件。

#### 2.2 配置环境变量

复制配置文件：

```bash
copy .env.example .env
```

编辑 `.env` 文件，修改为你的数据库配置：

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的 MySQL 密码
DB_NAME=jiandu_admin

JWT_SECRET=随机生成一个长字符串（可以用密码生成器）
JWT_EXPIRES_IN=24h

PORT=3000
```

### 3. 启动服务器

#### 开发模式（自动重启）

```bash
npm run dev
```

#### 生产模式

```bash
npm start
```

### 4. 访问后台

打开浏览器访问：http://localhost:3000

**默认管理员账户：**
- 用户名：`admin`
- 密码：`admin123`

⚠️ **首次登录后请立即修改密码！**

## 🐛 常见问题

### Q: 无法连接数据库
**A:** 检查以下几点：
- MySQL 服务是否已启动
- `.env` 文件中的数据库配置是否正确
- 数据库 `jiandu_admin` 是否已创建
- 数据库用户是否有足够权限

### Q: npm install 失败
**A:** 尝试以下方法：
- 清除 npm 缓存：`npm cache clean --force`
- 删除 `node_modules` 和 `package-lock.json` 后重新安装
- 使用淘宝镜像：`npm config set registry https://registry.npmmirror.com`

### Q: 端口被占用
**A:** 修改 `.env` 中的 `PORT` 为其他端口，如 `3001`

### Q: 忘记密码怎么办
**A:** 可以通过 MySQL 直接重置：

```sql
USE jiandu_admin;
UPDATE users 
SET password_hash = '$2a$10$YourNewHashHere' 
WHERE username = 'admin';
```

或者使用 bcrypt 生成新密码的 hash。
